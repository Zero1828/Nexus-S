# Requisitos de Rendimiento - Nexus-S

Este documento detalla las metas estrictas de consumo de hardware para mantener al sistema operativo ultra rápido y optimizado.

## 1. Control de Memoria RAM 
- **Meta base**: El sistema debe iniciar consumiendo un máximo de 500 MB de RAM.
- **Límite estricto**: El consumo total del sistema con servicios básicos nunca debe superar los 600 MB de RAM.
- **Optimización**: Se prohíbe el uso de programas basura (bloatware) o librerías pesadas en el espacio de usuario
## 2. Compatibilidad de Hardware
- **Arquitectura principal**: x86_64 (Procesadores Intel y AMD de 64 bits).
- **Soporte retro**: Diseñado para volar en computadoras viejas que los sistemas modernos consideran obsoletas.
- **Futuro**: Modularizado para expandirse a arquitectura ARM en versiones posteriores.
